# mondial-watch

Проверка сайта снаружи по расписанию GitHub Actions: раз в 10 минут — `/api/health` и главная
(код 200, время ответа, строка на странице), раз в сутки — карта сайта. Проверка не прошла два
раза подряд — запуск падает, GitHub пишет владельцу на почту.

- `.github/workflows/watch.yml` — расписание; адрес сайта — переменная репозитория `SITE_URL`.
- `watch.sh` — сами проверки. Это копия: источник и порядок обновления — в репозитории сайта.
- Первого числа каждого месяца workflow делает пустой коммит, чтобы расписание не выключилось.

Кода сайта здесь нет.
